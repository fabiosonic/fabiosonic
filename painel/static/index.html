Fila de ordens

Como executar

  1. Calibre a tela da Clear (uma vez): python -m swingbot calibrar
  2. Teste sem enviar: python -m swingbot ensaio PETR4 --preco 10
  3. Execute a fila: python -m swingbot executar-fila --real

O robô abre a Clear, aguarda seu login, mostra cada ordem e pede a confirmação OPERAR REAL. Para travar tudo, crie o arquivo PARAR na pasta do projeto.

monitor: python -m swingbot monitorar --real
