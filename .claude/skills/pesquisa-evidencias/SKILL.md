# Pesquisa de evidências

1. Antes de implementar algo "como no sistema de referência", procure a linha correspondente em `docs/evidencias.md`.
2. Classifique cada item como **verificado** (observado/mencionado com fonte e timestamp), **decisão de projeto** (requisito nosso, não comprovado) ou **futuro**.
3. Registre: funcionalidade, fonte + timestamp, o que foi observado/mencionado, limitações da evidência e comportamento do MVP.
4. Se a fonte for só descrição/transcrição, diga isso explicitamente. Nunca afirme equivalência com o sistema original.
5. Não copie marca, logotipo, aulas, análises pagas ou materiais proprietários; use conteúdo original.
