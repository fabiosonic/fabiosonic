# Revisão quatro olhos

Regra: o revisor **reexecuta** os números críticos a partir dos documentos, sem copiar o resultado do autor.

## Checklist geral

- [ ] Competência, cliente e regime corretos.
- [ ] Todos os documentos esperados foram considerados (comparar com o mês anterior).
- [ ] Os números críticos batem na reexecução (imposto, base, folha líquida, saldo bancário).
- [ ] As variações relevantes têm justificativa.
- [ ] Cada conclusão técnica tem fundamentação citada.
- [ ] Os dados pessoais estão minimizados no ticket.
- [ ] O que depende de humano está explícito (transmitir, emitir, assinar).

## Resultado

- **Aprovado** → move para "aguardando aprovação do Conselho".
- **Reprovado** → devolve ao autor com: item, valor esperado x encontrado e evidência.
- Registre a causa raiz do erro (falta de documento, regra errada, erro de cálculo, norma desatualizada).
